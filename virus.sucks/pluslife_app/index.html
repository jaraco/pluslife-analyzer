Changelog Änderungen

2026-10-26

  • Feature For PM001 devices, the app now automatically remembers the curve data of running tests. After a reconnect or an app restart, it tries to continue tracking the running test without losing the data from the previous session.
  • UX The app now refuses to connect to the same device in multiple tabs.
  • Core Update the test kit configuration for PM001 devices with SV2.2 and later.

2026-10-22

  • Feature Every test now gets a share link that others can open to follow the test live and see its result.
  • Feature You can now add extra metadata to tests - such as the sampling site - to help our research.
  • Feature In Expert Mode, curves can now be shown normalized, raw, or one panel per channel.
  • Feature The app now follows the system's dark mode.
  • Core Support PM003 and PM003 Ultra (veterinary) devices.

2026-10-18

  • Core Support PM005 and PM001 Ultra devices.
  • Bugfix Automatically re-establish a dropped Bluetooth connection to PM001/PM003 devices more reliably. This should particularly improve stability on iOS/Bluefy.

2026-10-07

  • Feature Update Pluslife test kit definitions. This adds new veterinary kits (Toxoplasma, FCoV, Giar/Trit/Parvo/Corona and CDV/CPIV/CAV-2/Bb/CIV/Mycoplasma).

2026-02-02

  • Feature Warn when Pluslife device reports zero values and automatically disable normalization.

2025-08-22

  • Feature On platforms other than iOS, the app now works offline and can be installed as a web app. Unfortunately, iOS does not properly support Progressive Web Apps (PWAs).

2025-06-30

  • Feature High-contrast mode for users with visual impairments.
  • Feature Webhooks for sending status updates to external services.

2025-06-27

  • Feature Add ability to load a JSON file in Expert Mode.
  • UX Add progress spinner to "Stop test" button.
  • UX Ask Google Translate to not translate the app.

2025-06-26

  • UX Show serial number without requiring expert mode.
  • UX Make the flu combination test specificity note even harder to miss.

2025-06-16

  • Feature Quick select for tests (making it harder to select the wrong test by accident).
  • UX Remove LOD data in Expert Mode. Pluslife has removed the LOD values from their data. Refer to the test instruction manuals for authoritative LOD values.
  • UX Show progress bar while the device heats up (without requiring expert mode).
  • Core Update pet test data.
  • Core Update human test data.

2026-10-26

  • Neu Bei PM001-Geräten merkt sich die App jetzt automatisch die Kurvendaten laufender Tests. Nach einem Verbindungsabbruch oder einem Neustart der App versucht sie, den laufenden Test weiterzuverfolgen, ohne die Daten der vorherigen Sitzung zu verlieren.
  • Bedienung Die App verbindet sich nicht mehr in mehreren Tabs mit demselben Gerät.
  • Technik Aktualisierte Test-Kit-Konfiguration für PM001-Geräte ab SV2.2.

2026-10-22

  • Neu Jeder Test erhält jetzt einen Link zum Teilen, mit dem andere den Test live verfolgen und das Ergebnis sehen können.
  • Neu Zu Tests können jetzt optional freiwillige Angaben gemacht werden - etwa die Abstrichstelle -, um unsere Forschung zu unterstützen.
  • Neu Im Expertenmodus lassen sich die Kurven jetzt wahlweise normalisiert, roh oder mit einem Diagramm pro Kanal anzeigen.
  • Neu Die App unterstützt jetzt Dark Mode, wenn das System das vorgibt.
  • Technik Unterstützung für PM003- und PM003 Ultra-Geräte (Tiermedizin).

2026-10-18

  • Technik Unterstützung für PM005 und PM001 Ultra-Geräte.
  • Fehlerbehebung Eine abgebrochene Bluetooth-Verbindung zu PM001-Geräten wird zuverlässiger automatisch wiederhergestellt. Das sollte vor allem die Stabilität unter iOS/Bluefy verbessern.

2026-10-07

  • Neu Aktualisierte Definitionen der Pluslife-Test-Kits. Neu sind Kits für die Tiermedizin (Toxoplasma, FCoV, Giar/Trit/Parvo/Corona und CDV/CPIV/CAV-2/Bb/CIV/Mycoplasma).

2026-02-02

  • Neu Warnung, wenn das Pluslife-Gerät Nullwerte meldet; die Normalisierung wird dann automatisch abgeschaltet.

2025-08-22

  • Neu Außer unter iOS funktioniert die App jetzt auch offline und lässt sich als Web-App installieren. Leider unterstützt iOS Progressive Web Apps (PWAs) nicht richtig.

2025-06-30

  • Neu Kontrastreicher Modus für Menschen mit Sehbeeinträchtigungen.
  • Neu Webhooks, die Statusmeldungen an externe Dienste senden.

2025-06-27

  • Neu Im Expertenmodus lässt sich eine JSON-Datei laden.
  • Bedienung Fortschrittsanzeige am Button „Test abbrechen“.
  • Bedienung Google Translate wird gebeten, die App nicht zu übersetzen.

2025-06-26

  • Bedienung Die Seriennummer wird auch ohne Expertenmodus angezeigt.
  • Bedienung Der Hinweis zur Spezifität des Grippe-Kombitests ist jetzt noch schwerer zu übersehen.

2025-06-16

  • Neu Schnellauswahl für Tests (so wird seltener versehentlich der falsche Test gewählt).
  • Bedienung Die LOD-Daten im Expertenmodus sind entfernt. Pluslife hat die LOD-Werte aus seinen Daten genommen. Maßgeblich sind die LOD-Werte in den Gebrauchsanweisungen der Tests.
  • Bedienung Fortschrittsbalken beim Aufheizen des Geräts (ohne Expertenmodus).
  • Technik Aktualisierte Testdaten für Haustiere.
  • Technik Aktualisierte Testdaten für Menschen.
